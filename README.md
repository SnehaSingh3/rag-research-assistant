# RAG Research Assistant

A retrieval-augmented generation (RAG) chatbot that answers questions about
research papers on RAG and retrieval for LLMs, with cited sources and a
measured evaluation of answer quality.

## Problem
Research papers are long and hard to search. This project lets you ask
questions across 50 papers and get grounded answers with citations.

## Tech Stack
Python, PyMuPDF, sentence-transformers, ChromaDB, BM25, FastAPI, Streamlit
